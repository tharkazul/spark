# Privacy Policy

The privacy policy lives in one place: [`server/public/privacy.html`](../server/public/privacy.html), served at **https://rooka.io/privacy**. `website/privacy.html` is a copy of it and must stay identical.

Edit the HTML, copy it to `website/`, and deploy the server. Keep it in line with the store description and privacy answers in [APP_STORE_METADATA.md](APP_STORE_METADATA.md).

The Markdown version that used to be here (last updated 6 August 2026) was out of date. For example, it said only "text inputs" go to Gemini. It was removed so it can't be mistaken for the current policy.
