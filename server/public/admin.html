New Discount Code

1 · What the code gives

rooka+ starts the moment the athlete applies the code, on iPhone and Android, with nothing to pay and no card needed. When it ends they go back to free and see the normal paywall. One free period per athlete, ever.

Athletes holding this code see this offering's paywall, with the prices Apple and Google will charge. The discount itself lives in the stores, so set these up first (several codes can share one offering):

  • App Store Connect: a monthly and a yearly subscription in the existing rooka+ group, each with an introductory offer for the discount (or priced at the discount for a permanent one). Submit them for review.
  • Play Console: two new base plans on rooka_plus, each with a “new customer acquisition” offer for the discount. Leave the existing monthly / yearly base plans alone.
  • RevenueCat: import the four products, attach them to the rooka entitlement, create the offering with Monthly and Annual packages under this identifier, and give it a paywall.

Older app builds are asked to update before they can use a store-offer code.

Counted per athlete, not per attempt

Any number of athletes can redeem this code.

Redemption window (optional)
